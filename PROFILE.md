# MediaCaption API

A credit-billed REST API for retrieving public YouTube transcripts, with single and bulk transcript jobs, job-level webhooks, and AI transcription/translation capabilities. Backed by a public OpenAPI 3.1 contract with bearer/X-API-Key authentication.

## APIs

- **Media Caption Public API** — REST API for fetching public YouTube transcripts synchronously and in bulk, with account/balance endpoints, job polling, and completion webhooks. Bearer API key or X-API-Key auth. (`https://api.mediacaption.io/v1`)

> MediaCaption exposes a single publicly consumable interface: a REST API for public YouTube transcripts documented by a public OpenAPI 3.1.0 contract at https://www.mediacaption.io/docs/openapi/mediacaption.v1.yaml. Auth uses bearer API keys (Authorization: Bearer mc_live_xxx) or X-API-Key. Endpoints include GET /user, GET /balance, POST /transcripts, POST /transcripts/bulk, GET /transcriptions/{id}, GET /jobs/{id}, plus job-level webhooks (job.completed, job.completed_with_errors, job.failed). No agent-native surfaces were found: no hosted or local MCP server, no llms.txt, and no published agent skills. Third-party YouTube-caption MCP servers exist but are unaffiliated with this provider.
