# Media Caption

> Credit-billed REST API for retrieving public YouTube transcripts, with single and bulk transcript jobs, AI transcription of uploaded or URL-referenced media, job polling, and signed job-level webhooks. Base URL https://api.mediacaption.io/v1; authenticate with `Authorization: Bearer mc_live_xxx` or `X-API-Key`.

Generated by API Evangelist on 2026-09-03 from the provider's public docs and OpenAPI contract; the provider serves no /llms.txt of its own.

## API operations

- GET /user — account profile
- GET /balance — credit balance
- POST /transcripts — synchronous public YouTube transcript (1 credit on success)
- POST /transcripts/bulk — async bulk job, up to 100 items
- POST /transcriptions — AI transcription of a media URL
- GET /transcriptions/{id} — retrieve a retained transcription before expiresAt
- GET /jobs/{id} — poll a job; cursor pagination over items
- POST /uploads, POST /uploads/{id}/parts, POST /uploads/{id}/complete, POST /uploads/{id}/resume, GET /uploads/{id}, DELETE /uploads/{id} — multipart local-file upload and AI transcription flow (3 GB limit; cancel before processing refunds reserved credits)

## Cautions for agents

- No idempotency keys: do not auto-retry timed-out POSTs — duplicates spend additional credits. Retry 429s after Retry-After.
- Store transcript content you need longer than 3 days; expired content returns transcription_expired.
- Only job-level webhook events exist in v1; poll GET /jobs/{id} for item detail.
